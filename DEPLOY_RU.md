# Инструкция по деплою — Приют для собак (волонтёры-выгульщики)

Стек: Next.js 16 + Prisma + PostgreSQL + S3-хранилище + NextAuth.
Все данные (БД и фото) должны храниться на серверах в РФ (152-ФЗ).

Инструкция ориентирована на **Timeweb Cloud** — у него есть готовый App
Platform для Node.js-приложений, managed PostgreSQL и S3-хранилище в одном
месте, сервера физически в РФ. Для VK Cloud / Яндекс Cloud шаги
аналогичны, меняются только названия разделов в панели.

---

## 1. Что подготовить заранее на Timeweb Cloud (зависит только от вас)

1. Зарегистрироваться на timeweb.cloud и зайти в панель управления
2. Создать **App Platform** приложение (раздел "Приложения" → "Создать
   приложение" → тип Node.js) — это самый простой способ, платформа сама
   развернёт контейнер и выдаст рабочий адрес, без ручной настройки VPS
3. Создать **managed базу данных PostgreSQL** (раздел "Базы данных" →
   "Создать базу" → PostgreSQL) и сохранить:
   - host, port, имя БД, логин, пароль
4. Создать **S3-хранилище** (раздел "Облачное хранилище" / "S3") →
   создать bucket и сохранить:
   - endpoint, регион, имя bucket, access key, secret key
   - сделать bucket публичным на чтение (public-read), чтобы фото
     открывались на сайте напрямую по ссылке
5. (опционально) Домен, привязанный к серверу через DNS

## 2. Настройка .env

Скопируйте `.env.example` в `.env` и заполните реальными значениями:

```
DATABASE_URL="postgresql://ЛОГИН:ПАРОЛЬ@ХОСТ:5432/ИМЯ_БД?schema=public"

S3_ENDPOINT="https://s3.timeweb.cloud"
S3_REGION="ru-1"
S3_BUCKET="ваш-bucket"
S3_ACCESS_KEY_ID="ваш-access-key"
S3_SECRET_ACCESS_KEY="ваш-secret-key"
S3_PUBLIC_URL="https://ваш-bucket.s3.timeweb.cloud"

NEXTAUTH_SECRET="сгенерируйте случайную строку (см. ниже)"
NEXTAUTH_URL="https://ваш-домен.ru"

PRIVACY_POLICY_VERSION="1.0"
```

Сгенерировать `NEXTAUTH_SECRET` можно командой:
```bash
openssl rand -base64 32
```

В App Platform эти переменные обычно задаются не файлом `.env`, а в
разделе настроек приложения "Переменные окружения" — впишите туда те же
самые пары ключ-значение.

## 3. Установка и применение схемы БД

```bash
npm install
npx prisma migrate deploy
```

Эта команда создаст все таблицы (users, enclosures, dogs, walks, consents)
в вашей базе данных автоматически — ничего писать в SQL вручную не нужно.
Если используете App Platform, эту команду можно указать как
"Build command" или выполнить один раз вручную через консоль/SSH,
которую обычно даёт панель управления приложением.

---

## 4. Сборка и запуск

```bash
npm run build
npm run start
```

В настройках App Platform укажите:
- Build command: `npm run build`
- Start command: `npm run start`

Платформа сама развернёт контейнер, выдаст адрес и будет автоматически
перезапускать приложение при сбоях. Если вместо App Platform вы
используете обычный VM-сервер (Timeweb Cloud Server) — рекомендуется
запускать через process manager **pm2**:

```bash
npm install -g pm2
pm2 start npm --name dog-shelter -- start
pm2 save
pm2 startup
```

---

## 5. Первый запуск

1. Откройте сайт → `/register` → зарегистрируйтесь как первый волонтёр
2. Перейдите в `/admin` → нажмите "Добавить вольер" → заполните данные,
   загрузите фото вольера и собак
3. Вернитесь на главную — убедитесь, что карточка отображается,
   кнопка "Хочу выгуливать" работает, статус-полоса окрашивается верно

---

## 6. Проверка юридической части (152-ФЗ)

- Страница `/privacy-policy` должна открываться и быть доступна по ссылке
  со страницы регистрации
- При регистрации галочка согласия обязательна — без неё форма не отправится
- Факт согласия фиксируется в таблице `consents` с датой и версией политики
- Убедитесь, что и БД, и S3-хранилище физически размещены в России
  (это гарантируется выбором провайдера на шаге 1)

---

## 7. Резервное копирование

У Timeweb Cloud есть кнопка "Снимок / Backup" в панели управления базой
данных — рекомендуется включить автоматический бэкап раз в сутки.

## Структура проекта (для справки)

```
src/
  app/
    page.tsx            — главная страница с карточками вольеров
    login/               — страница входа
    register/            — страница регистрации (с загрузкой аватара)
    admin/                — админ-панель (добавление/редактирование вольеров)
    privacy-policy/       — политика обработки персональных данных
    api/
      auth/[...nextauth]  — вход/выход (NextAuth)
      register/            — регистрация пользователя
      upload/               — загрузка фото собак в форме
      enclosures/           — список/создание вольеров
      enclosures/[id]        — редактирование/удаление вольера
      enclosures/[id]/claim  — "Хочу выгуливать" (закрепить вольер за собой)
      enclosures/[id]/walk   — "Гуляли" (отметить прогулку)
      enclosures/[id]/comment — сохранение комментария к вольеру
  components/
    EnclosureCard.tsx    — карточка вольера (вся логика кнопок и статусов)
    EnclosureForm.tsx    — форма создания/редактирования в админке
    Avatar.tsx            — аватар с кружком и первой буквой имени
    Header.tsx            — верхняя панель с профилем и выходом
  lib/
    auth.ts               — конфигурация NextAuth
    prisma.ts             — клиент базы данных
    s3.ts                 — загрузка фото в S3-хранилище
    status.ts             — логика расчёта цвета полосы статуса
prisma/
  schema.prisma          — схема базы данных (5 таблиц)
```
